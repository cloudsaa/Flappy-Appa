# Flappy Appa

A small **Flappy Bird-inspired 2D game** made with Unity and C#.

## About

Flappy Appa is a simple arcade game where the player controls Appa and tries to fly through gaps between obstacles without colliding with them.

This project was created as a learning project to practice:

- Unity fundamentals
- C# scripting
- 2D game development
- Physics and collision detection
- UI and game states
- Sprite and pixel-art workflows

## Built With

- Unity
- C#
- Aseprite

## Features

- Player movement and gravity
- Pipe/obstacle spawning
- Collision detection
- Score system
- Game over screen
- Pixel-art visuals
